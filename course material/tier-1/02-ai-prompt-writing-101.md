# AI Prompt Writing 101

## Overview

The difference between a useless AI answer and a brilliant one is the prompt. This course teaches the four-part formula behind every strong prompt — role, context, task, format — with before-and-after examples and a 20-prompt cheat sheet you can reuse daily. Master this and every AI tool you touch gets better.

## Lesson 1: The anatomy of a good prompt

A strong prompt has four parts. Think of it as briefing a new employee.

**Role** — Who is the AI being? "You are a senior accountant."
**Context** — What does it need to know? "My business is a 2-person salon in Mombasa."
**Task** — What exactly should it do? "Write a price list announcement."
**Format** — How should the answer look? "3 short paragraphs, under 100 words."

You do not need all four every time. But the more you give, the better the result. Weak prompts skip context and format, which is why they return generic fluff.

## Lesson 2: Weak prompt vs strong prompt

Look at the difference.

**Weak:** "Write a caption for my shop."

**Strong:**

```
You are a marketing copywriter for small Kenyan businesses.
My shop is a matatu accessories vendor in Thika. I am announcing
a 10% discount on phone holders this weekend, paid via M-Pesa.
Write one Instagram caption under 60 words with a call to action.
```

The strong prompt gave a role, the business, the offer, the payment method, the platform, a length, and a call to action. The answer is usable almost immediately.

**Weak:** "Help me with my CV."

**Strong:**

```
You are a CV writer who knows Kenyan employers. Rewrite my
work history into a one-page CV with bullet points that show
results. Here is my work history: [paste]. Target role: [role].
```

Same request, wildly different output. Practice converting weak prompts to strong ones and you will never go back.

## Lesson 3: How to fix a bad AI response

The first answer is rarely perfect. The skill is re-prompting — steering the AI toward what you want. Do not start a new chat. Keep talking.

**Tell it what's wrong.** "That's too formal. Write it the way a friend would say it."

**Add missing detail.** "Add that we deliver to all estates in Nakuru."

**Constrain the output.** "Cut it to 2 sentences. Remove the hashtags."

**Give it an example.** "Make it similar in tone to this: [paste an example]."

**Ask for options.** "Give me 3 versions — one playful, one professional, one short."

Re-prompting is free and fast. The worst first drafts become excellent final drafts in two or three rounds. This habit alone makes you look like a prompt expert.

## Lesson 4: Building your own prompt library

Every good prompt you write is an asset. Start a notes app file called "My Prompts" and paste the winners there. Over weeks you will build a personal cheat sheet for your exact business, job, or studies.

Organise by use: emails, captions, study, work, money. When a prompt works twice, keep it. When it fails, note the fix. This library is what Tier 2 courses help you turn into a full system — and eventually a paid service.

## Prompt Library

The 20 prompts below cover everyday Kenyan tasks. Copy, fill in the brackets, and reuse.

**Professional email**

```
You are a polite office assistant. Write an email to [recipient]
about [subject]. My name is [name]. Keep it under 120 words,
warm but professional.
```

**Follow-up message**

```
A client went quiet after I sent a quote of KES [amount] for
[service]. Write a friendly WhatsApp follow-up that is not pushy.
```

**Product listing**

```
Write a Jiji product listing for [item]. Price KES [amount].
Mention [2 features]. End with "Pay via M-Pesa, delivery
available in [town]".
```

**Announcement**

```
Write a short announcement for my [business] about [news].
End with a clear call to action. Keep it under 80 words.
```

**Explain simply**

```
Explain [concept] to a Form 2 student in Kenya. Use one local
example and keep it under 150 words.
```

**Summarise**

```
Summarise the text below into 5 bullets, keeping dates and
numbers exact: [paste text]
```

**Rewrite simply**

```
Rewrite this paragraph in simpler English, keeping the meaning.
Target reading level: high school: [paste text]
```

**Translate**

```
Translate this into natural Kiswahili, not literal: [paste text]
```

**Improve tone**

```
Rewrite this to sound more [warm/professional/confident]:
[paste text]
```

**Idea generation**

```
Give me 10 ideas for [goal]. Then pick the 3 most realistic for
someone with a budget of KES [amount].
```

**Meeting notes**

```
Turn these rough notes into clean meeting notes with decisions
and action items: [paste notes]
```

**Pricing help**

```
A customer says my price of KES [amount] is too high. Write a
reply that justifies the price without sounding rude.
```

**Learning plan**

```
Make me a 2-week plan to learn [topic] using free tools, 30
minutes a day. I am a complete beginner.
```

**Complaint reply**

```
A customer received a damaged item. Write an apology that offers
a replacement and keeps them as a customer. Business: [yours].
```

**Cover letter**

```
Write a cover letter for a [role] job at [company]. Mention my
skills: [skills]. Kenyan context, professional but warm.
```

**Speech**

```
Write a short speech for [occasion, e.g. a chama meeting].
Keep it under 2 minutes, heartfelt, not formal.
```

**Negotiation**

```
I need to ask my landlord for a rent reduction because of hard
times. Draft a respectful message explaining my situation.
```

**Bio**

```
Write a 2-line bio for my [business/personal brand] for Instagram
and LinkedIn. Mention what I do and where I am based.
```

**Proofread**

```
Proofread this for grammar and clarity. Keep my voice:
[paste text]
```

**Plan breakdown**

```
Break this big task into small daily steps I can finish in 20
minutes a day: [task]
```

## Common mistakes to avoid

- Writing prompts with no context and no format
- Restarting the chat every time instead of re-prompting
- Using one-word prompts for complex tasks
- Never saving prompts that work well
- Accepting a mediocre first answer as final
